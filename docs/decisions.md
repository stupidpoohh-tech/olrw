### D3·D5 미채택에 따른 스키마 처리

넣지 않기로 한 것도 **나중에 열 수 있는 문은 남긴다.** 빈 컬럼 하나가 나중의 마이그레이션보다 싸다.

- `volumes.met_at` — 채워 넣는다(`closed_at`과 같은 값). D3를 나중에 채택하면 여기가 만남 시각이 된다.
- `telegrams.retracted_at` — 만들지 않는다. `deleted_at`으로 충분하고, D5 미채택이므로 회수 개념 자체가 없다.
- `meetings` 테이블 — 만들지 않는다.

### 변하지 않는 것

디자인 값은 협상 대상이 아니다. `PORTING-SPEC.md` §3 토큰, §4 색, §6 타임라인·이징·사운드 파라미터를 그대로 옮긴다.
정원 4명 상한, 채팅 기능 금지, 반경 최대 6px, 액센트 `#8a3a31` 하나 — 전부 유지.

## D9 — 타자기: 색이 아니라 물건 네 대 (확정)

단계 2에서 발견. 번들 사진이 이미 무채색이라 §4-2 의 filter 여덟 개가 전부 같은 회색을 냈다
(가장 가까운 쌍 ΔE 1.0). 전보함을 색으로 구분한다는 장치가 동작하지 않았다.
근거는 `docs/AUDIT.md` §04-5.

**결정: CSS 필터를 버리고 색깔별 사진 여덟 장을 쓴다.** 원본이 있으므로 새로 제작해서 넣는다.

- `TypeColor.filter` 는 남기되 **폴백 전용**이다. 사진이 있으면 쓰이지 않는다.
- 사진 경로는 `public/assets/typewriter/{id}.webp`. 규격은 `docs/typewriter-photos.md`.
- 여덟 장이 다 들어오기 전까지는 기존 단일 사진 + 필터로 폴백한다 — 화면이 깨지지 않는다.
- 검사: `pnpm tint:check` (색 간 ΔE 8 이상)

`tint` 대표색 8종은 그대로다. 바뀐 것은 그 색에 도달하는 방법뿐이다.

## 단계 4에서 확인된 것

- **제본된 권은 지울 수 없다.** `volumes` 에 멤버용 delete/update 정책이 없고 권한도 회수돼
  있어, 서버 함수 없이는 삭제 경로 자체가 없다. 참조 구현에는 "되돌릴 수 없습니다" 확인 후
  하드 삭제가 있었지만 옮기지 않았다 — 스펙 §1 원칙 4("제본된 권은 삭제가 쉬우면 안 된다")와
  맞고, D5 를 미채택했어도 이건 스키마가 이미 정한 결과다. 필요해지면 별도 결정으로 연다.
- **전보 회수는 남긴다.** 작성자만, 소프트 삭제로. 되살리기는 서버가 막는다.
- **키 자리는 사진에 묶여 있다.** `src/features/transmit/keys.ts` 가 사진 기준 백분율로
  키캡 중심을 들고 있다. D9 사진이 들어오면 프레이밍이 같아야 이 표가 그대로 쓰인다.
  `pnpm ui:check4` 가 "A 를 누르면 A 키 자리에 온다"로 이걸 지킨다.

## 단계 5에서 정한 것

- **제본은 애니메이션과 나란히 돈다.** 참조 구현은 5.8초가 끝난 뒤에 `closeVol` 을 불렀다.
  서버가 느리거나 실패하면 사용자가 5.8초를 기다린 뒤 다시 기다리게 된다.
  지금은 `binding` 진입과 동시에 `close_volume` 을 부르고, 애니메이션이 끝날 때 결과를 기다린다.
  실패하면 표지 고르기로 돌려보내고 이유를 알린다.
- **표지 사진은 권보다 먼저 올라간다.** 권 id 를 알 수 없으므로 파일명은 uuid 로 짓는다
  (`covers/{box_id}/{uuid}.jpg`). `uploadCover(boxId, file)` 가 경로를 돌려준다.
- **모션을 줄이는 설정에서는 타임라인 자체를 건너뛴다.** CSS 로 애니메이션만 꺼 두면
  5.8초 동안 빈 화면을 보게 된다. `useReducedMotion()` 이 0.4초 뒤 결과로 보낸다.
- **금박 각인의 글자는 흰색이다.** 금색은 표지 테두리가 낸다 — 참조 구현의 값이 그렇다.
  완료 화면의 책 라벨만 금색(`--gold-light`)이다.

## 단계 6에서 정한 것

- **합성 함수는 `BaseAudioContext` 를 받는다.** 재생은 `AudioContext`, 검증은
  `OfflineAudioContext` 로 **같은 코드**를 돌린다. 오디오는 조용히 망가진다 —
  노드 연결 하나가 빠져도 화면은 멀쩡하고 소리만 안 난다.
  `pnpm sound:check` 가 §6-1 이 지정한 주파수(2200/3300Hz, 80Hz, 180→60Hz 등)가
  실제로 나오는지 Goertzel 로 잰다.
- **캐리지 쿵을 `setTimeout` 이 아니라 `t0 + 0.28` 로 예약한다.** 참조 구현은
  setTimeout 을 썼는데 탭이 바쁘면 밀린다. §6-1 의 "280ms 뒤"는 벽시계가 아니라
  소리의 시각이다.

### 남겨 둔 것 — 음소거

지금은 소리를 끌 방법이 없다. 참조 구현에도 없었고, 포팅 중 기능을 더하지 않는다는
원칙에 따라 넣지 않았다. 다만 타건음은 글자마다 울리므로 공공장소에서는 부담스럽다.
**7단계에서 다룰 후보다.** 넣는다면 전보함 설정이 아니라 기기 설정이어야 한다 —
소리는 개인의 상황이지 전보함의 성격이 아니다.

## D10 — 책등에 사진을 깔지 않는다 (확정)

사진 표지를 넣으면 책등이 대차게 잘렸다. 책등은 34×150px, 1:4.4 스트립이라
5:7 사진을 `cover` 로 깔면 가운데 세로 띠만 남는다. 게다가 금박 글자가 사진 위에서 묻히고,
긴 제목은 세로쓰기가 여러 열로 흩어졌다.

**결정: 책등은 사진의 대표색, 사진은 머리의 정사각 조각과 앞표지에서.**
실물 책의 논리 그대로다 — 책등에는 제목이 있고 사진은 앞표지에 있으며, 앞표지는 꺼내야 보인다.

- 대표색은 그릴 때 사진에서 계산한다(`coverTint.ts`). **스키마를 건드리지 않는다.**
  색상은 원형이라 벡터 합으로 내고, 명도를 24~36%로 눌러 금박 글자가 언제나 읽히게 한다.
- 책등 머리에 34×34 사진 조각. 실물 책의 레이블 자리다.
- 사진은 책을 펼치면 5:7 앞표지로 온전히 보인다.
- 제목은 `white-space: nowrap` + `text-overflow: ellipsis` 로 한 열 고정.
  `min-height: 0` 이 없으면 flex 가 눌러 한 글자만 남는다.
- 사진 위에 글자가 놓이는 곳(앞표지·완료 화면·제본 애니메이션)에 스크림을 넣었다.
  §4-3 이 요구한 것인데 빠져 있었다.

## D11 — ~~로그인 앞에 소개 화면~~ (D12 로 번복)

예전에는 로그인 화면이 먼저 섰다. 이 제품은 첫눈에 뭔지 알기 어렵다 —
전보함, 봉인, 제본, 서가. 계정을 만들기 전에 무엇인지 볼 수 있어야 한다.

- 로그인하지 않으면 `LandingScreen` 이 선다. 담는다 → 만나서 맺는다 → 아카이브,
  그리고 "이런 것은 없습니다".
- 설명 그림을 그리지 않는다. **앱에서 쓰는 그 컴포넌트**(`TelegramCard`, `SealedEnvelope`,
  책등)를 그대로 놓는다. 소개와 실물이 어긋날 수 없다.
- 해시로 상태를 남긴다(`#login` / `#join`). 화면이 하나 더 생긴 이상 뒤로 가기가
  소개로 돌아와야 한다. 로그인하고 나면 해시를 지운다.
- 로그아웃하면 로그인 화면이 아니라 소개로 돌아간다.


## D12 — 시작화면 없이 곧장 체험 모드 (확정 · D11 번복)

D11 은 소개 화면(LandingScreen)을 계정 화면 앞에 세워, 앱이 무엇인지 먼저 보여주려는
결정이었다. 그 뒤 D9(타자기 4대)를 채우고 안내 투어(GuestTour)를 만들면서 두 가지
사실이 분명해졌다.

- **투어가 소개를 이미 맡는다.** 온보딩 → 타전실 → 탭 → 만남 마감 4 스텝은
  랜딩의 세 절과 같은 것을 다룬다. 게다가 **실제 화면 위에서** 다룬다.
- **랜딩은 실물이 아니라 실물 조각이었다.** 카드와 봉투를 보여주지만 만질 수 없다.
  체험 모드 + 투어는 실제로 만질 수 있다 — "만나서 하고 싶은 말을 차곡차곡 담고,
  만나서 맺고, 아카이브한다" 를 진짜로 해 볼 수 있다.

그래서 랜딩을 없앤다.

- 미로그인 방문자는 곧장 체험 모드로 진입한다. `PublicGate` 가 방문 즉시
  `enterAsGuest()` 를 부른다.
- 로그인/가입은 게스트 배너의 링크(`#login` / `#join`)로 진입한다. AuthScreen 은
  유지되지만 앞 페이지가 아니라 옆 페이지다.
- 로그아웃하면 다시 게스트로 자동 진입한다. 로그인 화면이 다시 서지 않는다 —
  배너의 "로그인" 링크로 다시 들어간다.
- `src/features/landing/` 은 삭제한다.
