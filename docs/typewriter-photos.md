# 타자기 네 대

D9 결정: 사진 한 장에 필터를 걸어 색을 만들지 않는다. **네 대의 타자기**를 쓴다.
생김새도 소리도 다르다. 배경은 `docs/AUDIT.md` §04-5, 결정은 `docs/decisions.md` D9.

---

## 지금 있는 것

| id | 이름 | 그림 | 소리 |
|---|---|---|---|
| `steel` | 강철 | 담백한 블루그레이 | 밝고 마른 타건. §6-1 의 기본값 |
| `oak` | 참나무 | 나무 · 이끼 · 버섯 · 새 | 가장 낮고 둔탁. 몸통이 울린다 |
| `sugar` | 설탕 | 분홍 · 크림 · 체리 | 가볍고 높고 짧다. 유리 종 같은 벨 |
| `moss` | 이끼 | 민트 · 덩굴 · 꽃 · 달팽이 | 부드럽고 먹먹하다 |

파일은 `src/assets/typewriter/{id}.webp`, 정의는 `src/design/typewriters.ts` 한 곳에 모여 있다.
`public/` 이 아니라 `src/assets/` 다 — 빌드가 파일을 확인하고 해시를 붙인다.

## 한 대를 바꾸거나 더할 때

1. **그림** — 배경 투명, 가로 3:2, 폭 1000px 안팎의 WebP. 200KB 이하.
   배경이 흰색이면 지우고 넣는다(투명하지 않으면 페이지 위에 흰 사각형이 뜬다).

2. **자판 자리를 잰다.** 프레이밍이 타자기마다 달라도 된다 — 자리표를 각자 들고 있기 때문이다.
   대신 **그 표를 새로 재야 한다.** 네 줄 각각에 대해 세 값을 읽는다.

   | 값 | 뜻 |
   |---|---|
   | `y` | 키캡 중심의 세로 위치 (사진 높이의 %) |
   | `x0` | 맨 왼쪽 키의 가로 위치 (사진 폭의 %) |
   | `gap` | 키 사이 간격 (%) |

   재는 방법: 그림 위에 % 격자를 얹고 숫자열 · QWERTY · ASDF · ZXCV 네 줄의
   첫 키와 마지막 키를 읽는다. `gap = (마지막 − 첫) / (키 수 − 1)`.

3. **소리** — `voice` 를 정한다. 대역(`hp`)이 높을수록 밝고, 해머(`hammer`)가 낮고
   `hammerGain` 이 클수록 둔탁하다. 벨은 두 배음이다.

4. **검사**

   ```bash
   pnpm tint:check      # 네 대가 한눈에 다른가 · UI 점이 구분되는가
   pnpm sound:check     # 네 대가 다르게 들리는가 · 벨이 지정한 주파수에서 울리는가
   pnpm build && pnpm preview &
   pnpm ui:check4       # A 를 누르면 A 키 자리에 오는가
   ```
